2. 핵심 시스템 — 암살

구현 목표 
- 버튼 입력으로 애니메이션만 재생하는 방식에서 확장하여, 대상의 상태와 공간적 조건을 검사한 뒤 암살을 실행하도록 구성합니다. 
  조건을 만족하지 못하면 실행 함수를 조기에 종료하여 이후 정렬·몽타주 재생으로 넘어가지 않도록 합니다.

처리 흐름
1. E 입력을 받아 암살 중 재입력 여부를 확인합니다.
2. 암살 대상을 확보하고 유효성·생존 상태를 검사합니다.
3. 거리, 각도, 장애물 조건을 검사합니다.
4. 조건 통과 시 정렬과 Player·Enemy 몽타주 재생을 진행합니다.
5. 지정된 애니메이션 시점에 적의 체력·사망 상태를 처리하고 래그돌로 전환합니다.
6. 암살 종료 시 플레이어의 암살 상태를 해제하고 이동 입력을 복구합니다.

*미발각 조건과 피격 중단 규칙은 아래의 추가 연동·검증 항목에 구분했습니다.
